# 頭城地方記憶典藏｜史料重整第 1.1 版

本版修正「頭城國中舊校區拆除」日期為 2013 年 5 月 5 日，並將原《頭城生活指南》可確認的第一批資料整理為可搜尋、可分類、可導航的結構化清單。

生活指南資料屬易變動資訊，現階段均標示為「待確認」。後續將持續補齊原站項目並接入管理後台。

# 頭城地方記憶典藏 — 史料重整第一版

本版重點：

- 歷史年表預設由近到遠。
- 移除莊錫財手稿中所有直接與「吳沙」相關條目。
- 新增依使用者整理之《蘭陽博物館電子報》相關紀事。
- 將來源分為「官方／公共機構」「地方文史（待查證）」「頭城二三事／生活紀錄」。
- 保留頭城小故事、生活指南、李榮春人物頁與關於典藏。

## 部署

將本資料夾所有檔案放到 GitHub Repository 根目錄，於 Settings → Pages 選擇 main / root。

## 編輯原則

保存史料，不預設唯一答案；尊重不同觀點，持續校訂每一段頭城記憶。
