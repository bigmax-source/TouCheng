# 頭城地方記憶典藏 V4

一套可直接部署到 GitHub Pages 的頭城地方史、生活史與共同記憶網站。

## V4 內容

- 121 筆可搜尋紀錄，年代涵蓋 1731–2026
- 莊錫財 2010 年手稿辨識稿：77 筆
- 頭城二三事／網站補充整理：14 筆
- 全文搜尋、朝代、分類、資料來源與排序篩選
- 地方史手稿與生活史紀錄雙層資料標示
- 歷史漫遊、自適應時間軸、事件永久連結
- 深色模式、行動版導覽與減少動態效果支援

## 編輯原則

1. 原始手稿辨識文字不靜默改寫。
2. 網站補充事件與原始手稿分開標示。
3. 摘要、分類與「為什麼記錄」屬導覽與編輯層。
4. 日期、來源、照片與居民回憶可持續補證。
5. 特定史觀不視為唯一歷史敘事。

## 本次新增的網站補充紀錄

包括龜山島開放申請登島、雪山隧道通車、頭城鎮立圖書館遷館、文創頭圍園區、地方連鎖店開幕、《頭城二三事》Facebook 與 LINE 社群等。

## 部署

將 `toucheng-history` 目錄內所有檔案推送至 GitHub repository 根目錄，在 Settings → Pages 選擇 main branch / root 即可。
