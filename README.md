# 頭城地方記憶典藏 v1.4

本更新包以 v1.3 為基礎。解壓縮後，將資料夾內所有檔案與 `assets` 資料夾上傳並覆蓋 `bigmax-source/TouCheng` Repository 根目錄。

## 本版重點

- 全站導覽列統一使用「時間軸」
- 時間軸新增媽媽號與金魚厝邊資料及粉絲專頁連結，共 198 筆紀錄
- 時間軸主題分類整併為 10 類
- 生活指南移除四筆餐飲時間軸資料，新增室內修繕水電、教學服務與交通接送資料
- 生活指南刪除重複的舊站移植說明，修正金峰企業社回收項目與營業時間
- 「人物與觀點」改為可擴充的主題入口，保留李榮春與源合成街屋內容
- 李榮春新增「李榮春文學推廣協會」連結
- 「關於典藏」新增《頭城二三事》介紹、Facebook與LINE社群連結
- 全站快取版本更新為 v1.4

## 上傳方式

1. 解壓縮 `TouCheng-v1.4.zip`。
2. 進入解壓縮後的 `TouCheng-v1.4` 資料夾。
3. 將資料夾內的所有檔案與 `assets` 資料夾上傳至 GitHub Repository 根目錄。
4. 選擇覆蓋同名檔案並提交變更。
5. 等候 GitHub Pages 更新後，以無痕視窗確認網站。
