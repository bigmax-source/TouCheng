# 頭城地方記憶典藏 v1.6

這是可直接部署到 GitHub Pages 的完整靜態網站。v1.6 不增加新史料，重點是將既有資料整理成可研究、可校訂、可分批載入的地方知識庫。

## 本版重點

- 502筆原始資料經人工與程式校訂後整理為499筆事件。
- 合併「蘭陽博物館正式開幕」的重複紀錄，在同一事件下並列不同來源。
- 合併「下埔養殖漁業生產區公共設施改善工程」概括紀錄與1993年7月開工紀錄。
- 依人工判斷保留2007年2月13日「二城國小前鎮有土地施設學生遮雨棚」紀錄，移除3月13日衝突項目。
- 每筆事件新增日期、地點、行政里、人物、機構、主分類、次標籤、多筆來源、可信度及最後更新日期等固定欄位。
- 完整資料拆成24個年代JSON檔；首頁不再下載整份時間軸。
- 時間軸首次只渲染50筆，搜尋仍使用背景載入的完整499筆資料。
- 新增公開的「校訂與資料來源報告」，列出日期精度、共用來源網址與人工處理紀錄。
- 新增三條主題策展：烏石港的興衰、女性與家屋、雪山隧道後的頭城。
- 首頁新增典藏現況與最近校訂內容。

## 上傳方式

1. 解壓縮 `TouCheng-v1.6.zip`。
2. 進入 `TouCheng-v1.6` 資料夾。
3. 將資料夾內全部內容上傳並覆蓋 GitHub Repository 根目錄。
4. 請一併上傳新增的 `audit.html`、`curations.html`、`tools` 與 `assets/data/history` 資料夾。
5. 等候 GitHub Pages 更新後，以手機無痕視窗重新載入確認。

## 維護檔案

- `DATA-SCHEMA.md`：研究型事件資料欄位說明。
- `tools/history-source-v1.5.json`：本次遷移使用的唯讀母資料。
- `assets/data/history/manifest.json`：年代資料檔索引。
- `assets/data/audit-report.json`：機器可讀校訂報告。
