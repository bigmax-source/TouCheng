# 頭城地方記憶典藏 v1.5

這是可直接部署到 GitHub Pages 的完整靜態網站。解壓縮後，請將本資料夾內的所有檔案與 `assets` 資料夾上傳並覆蓋 `bigmax-source/TouCheng` Repository 根目錄。

## 本版重點

- 時間軸由 198 筆增加為 502 筆：完整匯入頭城鎮公所大事記，並加入微笑灣試露營、媽媽號台語小主播、第二屆紙飛機大賽與連明偉《槍強搶嗆》。
- 鎮公所大事記依已確認的文字校訂建檔；1980 年條目使用「石牌風景區」。
- 時間軸維持最多 10 種主題分類，資料來源整併為 5 類。
- 首頁與關於頁的紀錄數改為自動讀取，不再寫死；首頁分類入口可直接套用時間軸篩選。
- 首頁定位改為官方資料、地方出版、新聞、文學與居民生活紀錄並列。
- 「人物與觀點」依年齡脈絡加入李榮春、卓媽媽、林瑞文、連明偉、彭仁鴻，並保留源合成街屋；新增黏著式章節導覽。
- 「關於典藏」加入頭城二三事 LINE 互助社群 QR Code。
- 「頭城小故事」更新 2026 年人口與主任秘書設置門檻說明。
- 生活指南搜尋提示更新為診所、計程車、水電、開鎖與修冷氣。
- 新增集中式 `site-meta.js`，統一管理版本與更新日期。

## 上傳方式

1. 解壓縮 `TouCheng-v1.5.zip`。
2. 進入解壓縮後的 `TouCheng-v1.5` 資料夾。
3. 將資料夾內全部內容上傳到 GitHub Repository 根目錄。
4. 覆蓋同名檔案並提交變更。
5. 等候 GitHub Pages 更新後，以無痕視窗重新載入確認。
